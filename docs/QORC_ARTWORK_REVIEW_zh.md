# 图表视觉复核及修订

现版具备 ESWA 投稿所需的独立矢量图件、嵌入字体和可编辑表格。按 Nature 官方图件规范对标后，五张主图已统一字体、标题层级、留白与视觉编码，两张正文表格也重新排版。图表的数值、置信区间、显著性判定和不利结果均保持原样。

| 项目 | 修订结果 |
|---|---|
| 字体及层级 | Arial；普通图中文字 6.5–7 pt，分图字母 8 pt；字母与标题按固定物理间距排布 |
| 最终版面字号 | 183 mm 原始图宽；嵌入论文后的最小实际字形约 5.71 pt，超过 5 pt 下限 |
| 配色与可访问性 | 蓝、橙、紫统一映射数据集；曲线兼用实线/虚线/点线与圆/方/三角标记，黑白版本可区分 |
| 信息层次 | QORC 用蓝色突出；历史对照改为中性灰；文字保持深色；移除背景网格，保留必要参考线 |
| 排版及图例 | 紧凑化四分图；预算图采用共享图例，两张精度森林图沿用同一行顺序和显著性标记 |
| 统计呈现 | 森林图保留全部点位及配对 95% 区间；预算图保留所有设置曲线，描述性均值不伪装成推断性置信带 |
| 表格 | 三线表；数值右对齐；点估计与区间分别对齐；重复评价名称合并为清晰分组，说明置于表下 |
| 导出 | 五张 PDF/SVG 均为可编辑矢量文本，字体嵌入；PNG/TIFF 为 600 dpi |
| 自动及人工复核 | 五张图的面板对齐、字形尺寸与碰撞检查通过；全部面板及最终嵌入版面已检查 |

图件高度为 62–132 mm，所有比较、完整尾部、误差区间和预声明设置均保留。补充材料中的密集结果表沿用已核验且像素相同的版面。绘图脚本和独立图件随本版交付。

依据：[Nature 图件规范](https://research-figure-guide.nature.com/figures/preparing-figures-our-specifications/)、[Nature 初次提交指南](https://www.nature.com/nature/for-authors/initial-submission)、[Elsevier 图件要求](https://www.elsevier.com/about/policies-and-standards/author/artwork-and-media-instructions)。Nature 作为视觉基准，稿件的正式格式继续以 ESWA 为准。
